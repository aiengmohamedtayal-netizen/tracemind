# TraceMind Workspace Rules

This bundle contains repository-specific instructions for AI coding agents.

## Install
Copy the `.agents/rules/` directory into the root of the TraceMind repository.

Expected structure:

```text
tracemind/
└── .agents/
    └── rules/
        ├── 00-project-mandate.md
        ├── 01-workspace-boundaries.md
        ├── 02-architecture-boundaries.md
        ├── 03-domain-contracts.md
        ├── 04-intelligent-agent.md
        ├── 05-evidence-correlation.md
        ├── 06-hypotheses-timeline.md
        ├── 07-database-persistence.md
        ├── 08-ui-and-reporting.md
        ├── 09-testing-and-quality.md
        ├── 10-security-privacy.md
        ├── 11-six-member-workflow.md
        ├── 12-git-release-hygiene.md
        ├── 13-dependency-and-config.md
        ├── 14-documentation-and-diagrams.md
        └── 15-task-execution-protocol.md
```

## Important
Rules are instructions, not an operating-system security boundary. Configure Antigravity File Reads/Writes and terminal permissions separately. Start with read access to the repository and ask-before-write if you want approval on file changes.
